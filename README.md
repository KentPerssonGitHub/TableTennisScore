# TableTennisScore

Android app for tracking a table tennis match score.

## Project details

- Project name: `TableTennisScore`
- Package: `com.example.tabletennisscore`
- Min SDK: 26
- Target SDK: 35

## Build

```powershell
.\gradlew.bat assembleDebug
```

## Run on an emulator

```powershell
.\gradlew.bat installDebug
adb shell am start -n com.example.tabletennisscore/.MainActivity
```
